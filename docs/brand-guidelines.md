# Identidad visual

Referencia: Manual de Identidad Visual Institucional, código GCO-MA-001, versión 010, 29 de octubre de 2025.

Tokens institucionales, separados de los neutros de interfaz:

- `--brand-burgundy: #962D46`
- `--brand-blue: #2A477A`
- `--flag-yellow: #FFC800`
- `--flag-blue: #003189`
- `--flag-red: #D80025`

Tipografía principal: Nunito Sans, empaquetada con `@fontsource/nunito-sans`. Respaldo: Verdana, Arial, sans-serif. Verdana no sustituye el diseño.

No se dibuja el logotipo ni el escudo. `InstitutionalLogo` puede recibir más adelante un archivo autorizado. Por defecto muestra CONECTA 360 y el texto Prototipo de interoperabilidad empresarial.

Siempre visible: DEMO · DATOS SIMULADOS. El producto no sugiere aval ni patrocinio.
