# Guion de 15 minutos

1. Abrir el panel y decir que las cifras salen de 200 empresas ficticias. Mostrar el aviso de datos simulados. (2 min)
2. Entrar a Andina Ejemplo y recorrer resumen, finanzas y trazabilidad. Contrastar respuesta original y dato normalizado. (3 min)
3. Abrir Horizonte Ficticio desde Insolvencia. Mostrar la caída de ingresos, la regla de pasivos y el expediente. (3 min)
4. Abrir el catálogo, filtrar RUES y probar la conexión simulada. Recordar que el acceso real está por verificar. (2 min)
5. Ejecutar el flujo de perfil. En Observabilidad simular la caída de RUES, volver al flujo y mostrar el paro controlado. Recuperar el conector. (3 min)
6. Cerrar en Gobierno de datos con el caso del nombre abreviado y en Informes con la impresión. (2 min)

Frase de cierre: es un laboratorio para conversar una prueba de concepto. No está conectado a la Superintendencia ni a otras entidades.
