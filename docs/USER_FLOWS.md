# Recorridos

## Vigilancia

Bandeja → alerta abierta → ficha de la sociedad con `?alerta=` → Ver evidencia → Abrir expediente → volver a la bandeja.

## Dirección

Bandeja con panorama debajo de las tareas → sociedad en revisión → Informes → Descargar JSON o CSV, o Imprimir.

## Jurídico

Expedientes → detalle con actuaciones y nota → documentos del mismo expediente.

## Radicación

Documento → sociedad y trámite → extracción marcada como lectura de la plataforma → validación → confirmación del radicado `DEMO-RAD-LOCAL`.

## Integraciones

Catálogo con canal Real o Simulada → ficha del conector → Probar conexión o consulta externa si está configurada. El resultado externo no se une al identificador de la plataforma.
